- Al sustituir los datos reales desequilibrados por datos sintéticos perfectamente equilibrados, se garantiza una representación equitativa de las transacciones fraudulentas y legítimas.

- **Generando datos sintéticos para sobremuestrear la clase minoritaria (transacciones fraudulentas) o submuestrear la clase mayoritaria (transacciones legítimas), creando un conjunto de datos más equilibrado para el entrenamiento.**

- Al excluir por completo los datos reales desequilibrados y basarse únicamente en datos sintéticos para entrenar el modelo de detección de fraudes.

- Utilizando datos sintéticos para crear tipos completamente nuevos de transacciones fraudulentas, se mejora la capacidad del modelo para adaptarse a la evolución de los patrones de fraude.

Un consejo para este curso de Microsoft

Por todos los resúmenes que hemos hecho juntos, estoy viendo un patrón en las preguntas del examen:

GAN → cuando hablan de realismo, imágenes, audio, video o creación de contenido.
VAE → cuando hablan de privacidad, datos sensibles, espacio latente o generación de datos tabulares.
Transformers → cuando hablan de texto o lenguaje natural.
Modelos autorregresivos → generación secuencial.
Flow-Based Models → probabilidades exactas y transformaciones invertibles.

Ese patrón te va a ayudar a responder varias preguntas similares del examen.
