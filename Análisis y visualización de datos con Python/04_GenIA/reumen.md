## DIAPOSITIVA 3: ¿QUÉ ES LA INTELIGENCIA ARTIFICIAL?
- Definición: Campo de la informática que desarrolla sistemas capaces de aprender, adaptarse y realizar tareas que requieren inteligencia humana
- Diferencia clave con programación tradicional:
  - 📜 Tradicional: Sigue reglas predefinidas → Resultados predecibles
  - 🤖 IA: Aprende a partir de datos → Mejora continuamente
- ¿Cómo aprende? Analiza grandes volúmenes para identificar patrones, realizar predicciones y tomar decisiones
## DIAPOSITIVA 4: IA DISCRIMINATIVA VS IA GENERATIVA
IA Discriminativa IA Generativa Analiza datos existentes Crea contenido nuevo Clasifica y predice resultados Genera texto, imágenes, música, código Responde preguntas Crea respuestas completamente nuevas Aprende relaciones entre datos Aprende relaciones y genera nuevos ejemplos

Ejemplo:

- Discriminativa → Identifica si una imagen tiene un gato
- Generativa → Crea una imagen nueva de un gato que nunca existió

## DIAPOSITIVA 14: DATOS SINTÉTICOS - ¿QUÉ SON?
Definición: Datos creados artificialmente mediante IA que reproducen las propiedades estadísticas de los datos reales , pero no corresponden a personas/eventos reales

### 🎯 ¿Cuándo usarlos?
- Pocos datos disponibles
- Datos incompletos o con valores faltantes
- Información confidencial sensible
- Alta dificultad/costo para obtener nuevos datos
- Difícil acceso a escenarios reales
## DIAPOSITIVA 15: IMPUTACIÓN DE DATOS
Definición: Técnica para completar valores faltantes utilizando patrones aprendidos del propio conjunto de datos

### Diferencia clave:
Imputación Datos Sintéticos Completa valores faltantes en registros existentes Crea registros completamente NUEVOS

### Objetivos de la imputación:
- Reducir datos faltantes
- Mejorar calidad del dataset
- Facilitar entrenamiento de modelos
- Evitar eliminar registros incompletos

## DIAPOSITIVA 18: GAN - REDES GENERATIVAS ANTAGÓNICAS
Definición: Modelo de Deep Learning formado por dos redes neuronales que compiten entre sí para generar contenido ultra realista

### Componentes:
🎨 Generador (Falsificador)

- Crea datos sintéticos a partir de ruido aleatorio
- Intenta engañar al discriminador
- Mejora con la retroalimentación
🧐 Discriminador (Experto en Arte)

- Distingue entre datos reales y sintéticos
- Mejora detectando falsificaciones
- Devuelve retroalimentación al generador
## DIAPOSITIVA 19: ¿CÓMO FUNCIONA UNA GAN?
Proceso competitivo de 6 pasos:

1. 🎲 Se genera ruido aleatorio (materia prima)
2. 🎨 El Generador transforma el ruido en datos sintéticos
3. 🧐 El Discriminador recibe datos reales + sintéticos
4. 📊 El Discriminador clasifica: ¿real o falso?
5. 💬 Devuelve retroalimentación al Generador
6. 🔁 Se repite MILES DE VECES → Ambos mejoran 💡 Resultado: El Generador produce contenido tan real que es casi indistinguible

## DIAPOSITIVA 23: VAE - AUTOCODIFICADORES VARIACIONALES
Arquitectura: Encoder → Espacio Latente → Decoder

### Funcionamiento:
1. Encoder comprime los datos en un espacio latente (representación matemática simplificada)
2. Decoder reconstruye los datos desde el espacio latente
3. Para generar nuevos datos → seleccionar un punto del espacio latente y decodificarlo
### Ventajas sobre GAN:
✅ Entrenamiento más estable
 ✅ Mejor comprensión de la estructura de datos
 ✅ Control preciso de las características generadas (ej: edad, género, expresión facial en rostros)
✅ Espacio latente interpretable
