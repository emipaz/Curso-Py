# Aprovechamiento de los datos sinteticos en al Aprendizaje Supervisado

## Un equipo de científicos de datos está trabajando en un proyecto para desarrollar un modelo de aprendizaje automático que pueda predecir la pérdida de clientes para una empresa de telecomunicaciones. Disponen de una cantidad limitada de datos reales de clientes, y no son representativos de los diversos datos demográficos y comportamientos de la base de clientes de la empresa. ¿Cuál de las siguientes opciones describe cómo el equipo podría utilizar datos sintéticos para mejorar su modelo? Seleccione la mejor respuesta.

- Utilizar datos sintéticos para crear un entorno virtual en el que el modelo pueda interactuar con clientes simulados y aprender de su comportamiento.
- Utilice datos sintéticos para crear simulaciones de diferentes campañas de marketing y estrategias de retención de clientes.
- **Genere perfiles sintéticos de clientes que reflejen una gama más amplia de datos demográficos, comportamientos y patrones de rotación.**
- Generar datos sintéticos para aumentar los datos de clientes reales existentes, creando un conjunto de datos más amplio para entrenar el modelo.

> Correcto Esto permitiría al equipo entrenar su modelo con un conjunto de datos más diverso y representativo, lo que mejoraría la precisión y reduciría el sesgo.


## Un equipo de ciencia de datos está desarrollando un modelo de aprendizaje automático para predecir los fallos de los equipos en una planta de fabricación. Disponen de un pequeño conjunto de datos de averías reales de equipos, que es insuficiente para entrenar un modelo fiable. ¿Cómo puede el equipo utilizar datos sintéticos en este escenario para mejorar el rendimiento del modelo? Seleccione todo lo que corresponda.


- Entrenar el modelo exclusivamente con datos sintéticos para evitar el ruido y las incoherencias presentes en los datos del mundo real.

- **Generar datos sintéticos que imiten los patrones y las características de los fallos reales de los equipos para aumentar los datos de formación.**

> Correcto Esto aumentaría el tamaño y la diversidad del conjunto de datos de entrenamiento, lo que daría lugar a un modelo más sólido y preciso.

- **Utilizar datos sintéticos para simular distintos tipos de averías de los equipos, incluidos los casos raros o extremos que no están bien representados en los datos reales.**

> **Correcto Esto permite que el modelo aprenda a reconocer una gama más amplia de modos de fallo, mejorando su capacidad de generalizar y predecir fallos en diversas situaciones.**      

- **Crear datos sintéticos que representen el funcionamiento normal del equipo para equilibrar el conjunto de datos y evitar que el modelo se ajuste en exceso a los casos de fallo.**

> Correcto Incluir datos sintéticos de funcionamiento normal ayuda a que el modelo aprenda a diferenciar entre condiciones normales y defectuosas con mayor eficacia                                                                                                


## Un equipo de investigación está desarrollando un modelo de aprendizaje automático para identificar los primeros signos de una enfermedad rara utilizando los registros médicos de los pacientes. Sin embargo, les preocupa la privacidad de los pacientes y la seguridad de los datos. ¿Cuál de las siguientes técnicas puede ayudarles a utilizar los datos sintéticos de forma responsable en este escenario? Seleccione la mejor respuesta.

- Replicación directa: Creación de datos sintéticos que duplican exactamente la historia clínica original, incluida toda la información identificativa.
- Compartir modelos: Compartir el modelo de aprendizaje automático entrenado con otros investigadores sin revelar los datos originales o sintéticos utilizados para entrenarlo.
- **Animización: Eliminar toda la información identificativa, como nombres y direcciones, de los registros médicos originales antes de generar datos sintéticos.**
- Aumento de datos: Aumentar el tamaño del conjunto de datos existente añadiendo más registros médicos reales de pacientes, aunque contengan información identificativa.

> Correcto La anonimización ayuda a proteger la intimidad del paciente garantizando que no se incluya información personal en los datos sintéticos.

## Una empresa está desarrollando un modelo de Aprendizaje automático para predecir el rendimiento de los empleados a la hora de tomar decisiones de contratación y promoción. Planean utilizar datos sintéticos para aumentar su conjunto de datos limitado de registros de empleados existentes. ¿Qué consideraciones éticas debería priorizar la empresa para garantizar un uso responsable de los datos sintéticos en este escenario? Seleccione todo lo que corresponda.

- **Anonimización de datos: Eliminar o enmascarar cualquier información de identificación personal de los registros originales de los empleados antes de generar datos sintéticos para proteger la privacidad de los empleados.**

> Correcto Proteger la privacidad de los empleados es esencial cuando se manejan datos sensibles como los registros de rendimiento. Las técnicas de anonimización ayudan a mitigar los riesgos para la privacidad.

- **Validación de la precisión: Evaluar la precisión y representatividad de los datos sintéticos en comparación con los datos reales para garantizar que reflejan los patrones de rendimiento reales de los empleados.**

> Correcto Los datos sintéticos tienen que reflejar fielmente los datos del mundo real para que sean útiles para entrenar un modelo fiable y justo.

- **Mitigación de sesgos: Garantizar que los datos sintéticos no amplifiquen los sesgos existentes en el conjunto de datos original, como los relacionados con el sexo, la raza o el origen socioeconómico, que podrían dar lugar a resultados discriminatorios.**

> Correcto Es crucial abordar los posibles sesgos de los datos originales para evitar crear un modelo discriminatorio.

- Análisis costo-beneficio: Determinar si los beneficios potenciales del uso de datos sintéticos, como la mejora de la precisión del modelo, compensan los costes de la generación de datos y los posibles riesgos éticos.


## Una agencia de noticias utiliza datos sintéticos para crear un vídeo falso de un candidato político dando un discurso. ¿Cuál es el problema ético más importante asociado a este uso de datos sintéticos? Seleccione la mejor respuesta.

-Violación de la privacidad: El deepfake podría revelar información privada del candidato político que no pretendía hacer pública.

- Desplazamiento de empleo: El uso de deepfakes podría provocar la pérdida de puestos de trabajo en la industria de los medios de comunicación, ya que pueden utilizarse para crear vídeos realistas sin necesidad de actores humanos.

- **Desinformación y manipulación: El deepfake podría utilizarse para difundir información falsa o manipular la opinión pública, influyendo potencialmente en los resultados electorales.**

- Infracción de los derechos de autor: El deepfake podría utilizar la imagen y la voz del candidato político sin su permiso, violando sus derechos de propiedad intelectual.

> Correcto Esta es la preocupación ética más importante. Los deepfakes pueden utilizarse para crear contenidos engañosos que pueden tener graves consecuencias en un contexto político.
