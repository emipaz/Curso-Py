## ¿Cuál de las siguientes afirmaciones describe mejor cómo aprende de los datos un algoritmo de red neuronal? Seleccione la mejor respuesta.

- Utiliza un Árbol de decisiones para tomar decisiones secuenciales basadas en características de entrada.
- Agrupa puntos de datos similares en función de sus características inherentes.
- Crea un modelo lineal que representa la relación entre las características de entrada y las etiquetas de salida.
- **Ajusta los pesos de las conexiones entre neuronas para minimizar el error entre las predicciones del modelo y las etiquetas verdaderas.**

> Correcto Este es el principio básico del aprendizaje de las redes neuronales. Ajustan iterativamente los pesos de las conexiones para mejorar sus predicciones.

## Imagine que está desarrollando un programa para ayudar a los agricultores a predecir el rendimiento de sus cosechas. Seleccione la mejor respuesta.

- Aprendizaje por refuerzo
- Aprendizaje supervisado
- Aprendizaje no supervisado
- **Aprendizaje profundo**

> Correcto El aprendizaje supervisado utiliza datos etiquetados (rendimientos de cultivos anteriores con las condiciones correspondientes) para entrenar el modelo de predicción.

## Está trabajando en un proyecto para crear un modelo de Aprendizaje automático que pueda identificar diferentes tipos de aves a partir de imágenes. Tienes miles de imágenes de aves y sus etiquetas correspondientes (por ejemplo, "petirrojo", "arrendajo azul", "cardenal"). ¿Cómo utilizaría estos datos para "entrenar" su modelo de aprendizaje automático para identificar con precisión las especies de aves? Seleccione la mejor respuesta.

- Codifique manualmente las reglas de identificación de cada especie en función de sus características visuales.
- Introduzca las imágenes sin etiquetas y deje que el modelo descubra las especies por sí solo.
- Utiliza las imágenes para crear un entorno virtual en el que el modelo pueda interactuar con las aves y aprender sobre ellas.

- **Alimentar las imágenes etiquetadas al modelo, permitiéndole aprender patrones y asociarlos con las especies correctas**

> Correcto Este es el núcleo del aprendizaje supervisado, en el que el modelo aprende de los datos etiquetados para hacer predicciones.

- **Si el cliente canceló su suscripción**
- Edad del cliente

Seleccione todas las que corresponda.

- Aprendizaje no supervisado
- **Mejora del modelo**

> Correcto Las técnicas de mejora de modelos son esenciales para garantizar que el modelo se generalice bien y proporcione evaluaciones precisas en imágenes nuevas no vistas.

- Aprendizaje por refuerzo
- **Aprendizaje supervisado**
