## Está trabajando con un conjunto de datos de información de clientes, incluido su historial de compras, datos demográficos e interacciones en el sitio web. Desea crear un modelo que prediga qué clientes tienen más probabilidades de realizar una compra en el próximo mes. ¿Qué tipo de Aprendizaje automático sería el más adecuado para esta tarea y por qué? Seleccione la mejor respuesta.

- Aprendizaje no supervisado, porque desea descubrir patrones ocultos y agrupar clientes similares.
- **Aprendizaje supervisado, porque se dispone de datos etiquetados (compras anteriores) para entrenar un modelo que prediga resultados futuros.**
- Aprendizaje de refuerzo, porque se quiere crear un agente que aprenda por ensayo y error interactuando con los datos del cliente.
- Aprendizaje profundo, porque tiene un conjunto de datos grande y complejo que requiere un modelo sofisticado con múltiples capas.

> Correcto El aprendizaje supervisado es la mejor opción en este caso, ya que puede utilizar datos de compras anteriores para entrenar un modelo que prediga el comportamiento de compra futuro.
